# Agent Usage Guide

This directory contains specialized agent prompts for different aspects of development.

## Structure

- `project-context.md` - Base context inherited by all agents
- `agents/` - Specialized agent prompts organized by domain

## Agent Categories

### Backend (`agents/backend/`)
- `api-architect.md` - API design and architecture
- `backend-developer.md` - Backend implementation
- `database-engineer.md` - Database design and optimization
- `integration-specialist.md` - Third-party integrations
- `caching-specialist.md` - Caching strategies

### Frontend (`agents/frontend/`)
- `component-architect.md` - Component architecture and patterns
- `frontend-developer.md` - Frontend implementation
- `api-integration.md` - Frontend-backend integration
- `ui-specialist.md` - UI/UX implementation

### Testing (`agents/testing/`)
- `test-strategy.md` - Overall testing strategy
- `backend-testing.md` - Backend test implementation
- `frontend-testing.md` - Frontend test implementation
- `e2e-testing.md` - End-to-end testing
- `security-testing.md` - Security testing

### DevOps (`agents/devops/`)
- `infrastructure-architect.md` - Infrastructure design
- `terraform-specialist.md` - Terraform/IaC
- `kubernetes-specialist.md` - Kubernetes deployment
- `gateway-specialist.md` - API gateway configuration
- `cicd-specialist.md` - CI/CD pipelines
- `monitoring-specialist.md` - Observability and monitoring

## Usage

Reference an agent prompt when you need specialized expertise for a task.
